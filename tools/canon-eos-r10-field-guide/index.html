      Firmware 1.7.0 · released July 2025
      1. 1
        Stronger security: set a password firstThe camera asks for a password to be set up. It lives in Set-up 6 › Manage password.
      2. 2
        Software development kit supportAdds support for Canon's EDSDK / CCAPI, so third-party and custom software can control the camera.
      3. 3
        Online firmware updatesWith an internet connection, the camera can fetch new firmware from Canon's servers (Set-up 5 › Firmware).
      4. 4
        Fix: freeze with AF switchingFixed a freeze when the One-Shot AF→Servo AF button and the shutter button are pressed together.
      5. 5
        Fix: EF lens stabilisationFixed image stabilisation sometimes stopping with EF lenses on an adapter.

      Shows the body (and attached RF lens) firmware. 1.7.0 is the current R10 release; it includes every earlier fix, so there's nothing in between to install.
